# AdOps Advisor 初回商談・ヒアリング設計

## 1. 目的

この初回商談は、AdOps Advisorを売り込む場ではなく、Pre-SaaSで検証すべき以下を見極める場にする。

- 広告運用に関する痛みが本当に強いか
- 既存の代替手段に不満があるか
- 広告データ連携とAI相談に対する信頼・不安がどこにあるか
- 月額課金または検証費用への支払い意思があるか
- 導入に必要な条件、社内承認、セキュリティ条件が現実的か
- read-only / human-in-the-loop の価値が伝わるか

対象ICPは、月広告費50万〜500万円の自社EC/D2Cまたは小規模BtoB。代理店向けマルチクライアント運用や、媒体設定の自動変更ニーズはMVP対象外とする。

## 2. 商談の基本姿勢

- 60分を目安にする
- 冒頭で「今日は売り込みではなく、現場課題と導入条件の確認が目的」と伝える
- デモは長くても10分に留める
- 相手の理想論ではなく、直近30〜90日の具体的な困りごとを聞く
- 「AIが広告を自動運用します」ではなく「AIが分析・提案・人間向け作業手順を作ります」と説明する
- 秘密情報、OAuth token、API key、顧客リストは受け取らない

## 3. 推奨アジェンダ

| 時間 | 内容 | 目的 |
| --- | --- | --- |
| 0〜5分 | 前提説明 | 売り込みではなく検証面談であることを合わせる |
| 5〜15分 | 事業・広告運用体制 | ICP条件と意思決定構造を把握する |
| 15〜30分 | 現在の痛み | 課題の頻度、深さ、既存代替を確認する |
| 30〜40分 | 導入条件 | データ連携、権限、セキュリティ、社内承認を確認する |
| 40〜50分 | 支払い意思 | 予算感、支払主体、比較対象を確認する |
| 50〜60分 | 次アクション | PoC候補か、リサーチ対象か、対象外かを仮判定する |

## 4. 質問リスト

### A. ICP確認

1. 現在の月間広告費はおおよそいくらですか。
2. 広告媒体は何を使っていますか。Google、Meta、Yahooの比率はどのくらいですか。
3. 広告運用は自社内、代理店、兼任体制のどれですか。
4. 広告成果の責任者は誰ですか。日々の管理画面を見る人と意思決定者は同じですか。
5. 主要なCVは何ですか。EC購入、資料請求、問い合わせ、無料登録など、どこを成果と見ていますか。
6. 目標KPIは何ですか。CPA、ROAS、売上、商談数、LTVなど、優先順位を教えてください。

### B. 直近の運用課題

1. 直近1〜3か月で、一番困った広告運用上の問題は何ですか。
2. CPA悪化、CVR低下、CTR低下、ROAS悪化などが起きたとき、最初にどこを見ますか。
3. 「なぜ悪くなったのか分からない」と感じる頻度はどのくらいですか。
4. 改善施策を決めるまでに、通常どのくらい時間がかかりますか。
5. 施策後に結果を振り返る仕組みはありますか。
6. 広告媒体ごとに見るべき数字が分かれていて、優先順位付けに困ることはありますか。
7. 広告運用の判断で、社内説明や上長説明に困ることはありますか。

### C. 現在の代替手段

1. 今は誰に相談していますか。代理店、媒体担当、社内の詳しい人、ChatGPT、YouTube、記事など。
2. レポートやダッシュボードは何を使っていますか。
3. その方法で満足している点、不満な点は何ですか。
4. 代理店を使っている場合、依頼から回答までのリードタイムはどのくらいですか。
5. ChatGPTなどの汎用AIを広告運用に使ったことはありますか。使った場合、何が足りませんでしたか。
6. 現在のやり方に毎月いくら払っていますか。外注費、ツール費、社内工数を含めて教えてください。

### D. AdOps Advisorの価値仮説確認

1. 広告データを読み取り、AIが「原因仮説、推奨アクション、人間向け作業手順」を出すとしたら、どの場面で使いたいですか。
2. AIに一番聞きたい質問を、実際の言い方で3つ挙げると何ですか。
3. 「媒体設定はAIが直接変更せず、人間が確認して実行する」形は安心ですか、それとも物足りないですか。
4. どの粒度の回答なら実務で使えますか。初心者向け説明、数値根拠、管理画面の操作手順、上長向け要約など。
5. AI提案を採用する前に、必ず確認したい情報は何ですか。
6. どのような回答が出たら「信用できない」と感じますか。
7. 成果改善より先に、時間短縮、判断の安心感、社内説明のしやすさに価値を感じますか。

### E. データ連携・セキュリティ条件

1. Google Ads、Meta Ads、Yahoo Adsの管理者権限または連携許可を持っている人は誰ですか。
2. read-only OAuth連携なら許可できますか。
3. 広告アカウント名、キャンペーン名、指標データを外部SaaSに連携する際の社内確認は必要ですか。
4. 連携NGなデータはありますか。顧客リスト、個人情報、売上データなど。
5. セキュリティチェックシート、NDA、利用規約、DPAなどは必要ですか。
6. 導入前に必要な承認者は誰ですか。マーケ責任者、代表、情シス、法務、経理など。

### F. 支払い意思

1. この課題を解決するために、今すでに費用や時間を使っていますか。
2. 月に何時間くらい、広告分析・改善方針決め・社内説明に使っていますか。
3. このツールが月10時間の削減、判断精度の向上、施策漏れの防止に効く場合、月額いくらなら検討できますか。
4. 月額1万円、3万円、5万円、10万円だと、それぞれどう感じますか。
5. 有料PoCとして1〜2か月試す場合、いくらまでなら社内承認なし、または簡易承認で進められますか。
6. 支払いの決裁者は誰ですか。予算科目は広告費、ツール費、外注費のどれに近いですか。
7. どの状態になれば継続課金してもよいと判断しますか。

### G. 導入タイミング・次アクション

1. いつからなら試せますか。
2. 初回検証で見たい媒体と広告アカウントはどれですか。
3. 初回検証で扱いたいテーマは何ですか。CPA悪化、ROAS改善、初期設計、媒体横断比較など。
4. 検証期間中、週1回30分のフィードバック面談は可能ですか。
5. 検証結果を判断する成功条件を一緒に決めるなら、何を見たいですか。
6. 次回、広告データのサンプルまたは画面共有で実課題を見せてもらうことはできますか。

## 5. 深掘り質問

相手の回答が抽象的な場合は、以下で具体化する。

- それは直近いつ起きましたか。
- そのとき誰が、何を見て、どう判断しましたか。
- 判断に迷った理由は何でしたか。
- 結局どの施策を実行しましたか。
- その施策はうまくいきましたか。
- うまくいった、または失敗した理由は後から分かりましたか。
- もしその場でAIが分析と手順を出していたら、何が変わっていましたか。

## 6. 合格基準

初回商談後、以下を満たす場合はPre-SaaS PoC候補とする。

### 必須条件

- 月広告費が50万〜500万円の範囲、または近い範囲にある
- 自社側に広告成果への責任者がいる
- Google Ads、Meta Ads、Yahoo Adsのいずれかを実運用している
- 直近90日以内に、広告運用判断で困った具体例がある
- read-onlyデータ連携に原則前向きである
- AIによる分析・提案・人間向け作業手順に価値を感じている
- 媒体設定をAIが直接変更しない方針を受け入れられる
- 週1回程度のフィードバックに協力できる

### 強い合格シグナル

- 「CPA悪化の原因が分からない」「次に何を見るべきか分からない」が頻繁に出る
- 代理店や社内詳しい人への相談待ちがボトルネックになっている
- ChatGPTを試したが、自社広告データとつながらず実務に使えなかった
- 管理画面の操作そのものより、判断・優先順位付け・社内説明に困っている
- 月3万〜10万円程度の支払い余地がある
- 有料PoCに前向きで、決裁者または強い推進者が同席している
- 「次回、実データで試したい」という具体的な次アクションが出る

## 7. 不合格基準

以下に該当する場合は、MVP初期の優先対象から外す。

- 月広告費が小さすぎて、課題解決による経済効果が薄い
- 月広告費が大きく、既に専任チームや高度なBI基盤があり、要求がエンタープライズ寄り
- 代理店に完全委託しており、自社側で判断・実行する意思がない
- 求めている価値が「AIによる自動入札変更、予算変更、広告入稿」である
- read-only OAuth連携すら難しい
- セキュリティ要件が現段階のPre-SaaSで満たせない
- 広告運用の課題が曖昧で、直近の具体例が出ない
- 支払い主体、決裁者、検証タイミングが不明確
- 無料なら使うが、有料検証やフィードバック協力には消極的

## 8. 判定スコア

商談後、各項目を0〜2点で採点する。合計12点以上をPoC候補、8〜11点を継続ヒアリング、7点以下を優先度低とする。

| 項目 | 0点 | 1点 | 2点 |
| --- | --- | --- | --- |
| ICP適合 | 対象外 | 一部近い | 月広告費・業種・体制が合う |
| 痛みの強さ | 抽象的 | たまに困る | 頻繁かつ具体例がある |
| 既存代替の不満 | 現状満足 | 一部不満 | 明確な不満と乗り換え余地 |
| 支払い意思 | なし | 価格次第 | 有料PoCまたは月額に前向き |
| 導入容易性 | 権限・承認が重い | 一部確認が必要 | read-only連携と承認が現実的 |
| フィードバック協力 | 難しい | 月1回程度 | 週1回可能 |
| human-in-the-loop適合 | 自動運用が必須 | どちらでもよい | 人間確認前提を好む |
| 次アクション明確さ | なし | 後日検討 | 次回日程・データ・テーマが明確 |

## 11. PoC提案条件

PoCを提案する場合は、以下を明確にしてから出す。

- 検証期間: 2〜4週間
- 対象媒体: まず1〜2媒体
- 対象テーマ: 1つに絞る
- 成功条件: 時間削減、判断の質、施策化率、社内説明のしやすさなど
- フィードバック頻度: 週1回30分
- データ範囲: 広告指標、キャンペーン名、広告グループ名など必要最小限
- 禁止事項: 媒体設定の自動変更、secret/tokenのAI共有、成果保証
- 支払い: 無料検証にする場合も、有料化条件と想定価格を必ず確認する

## 12. この商談で検証する仮説

1. 月広告費50万〜500万円の自社EC/D2C・小規模BtoBは、広告運用の専門判断に継続的な不安を持っている。
2. 彼らは高度なBIよりも、次に何を見るべきか、何をすべきかを教えるAI Advisorに価値を感じる。
3. 媒体writeなしでも、分析・提案・人間向け作業手順に月額課金価値がある。
4. read-only OAuth連携は、Pre-SaaS導入の現実的な許容ラインになる。
5. 支払い意思は、成果保証よりも、判断時間削減、施策漏れ防止、社内説明のしやすさで発生する。
