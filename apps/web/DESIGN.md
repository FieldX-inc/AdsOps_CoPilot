# ちょこっとインハウス LP Design Guide

このLPは、画像生成したモックを正とする。実装時は「青い一般的なSaaS」ではなく、以下のトンマナに寄せる。

## コンセプト

- 頼れるけど重くない、広告運用のAI相談役
- ダッシュボードSaaSではなく、広告管理画面の数字を「次の一手」に変える相談体験
- human-in-the-loop前提。AIが勝手に広告設定を変更しない安心感を明示する

## 見た目

- 背景はほぼ白。薄いミントをセクション背景にだけ使う
- 主色はティール `#008c7a` / `#007f70`
- 文字は濃紺チャコール `#14213a`
- CTAの差し色に黄色 `#f5c84b`
- ヒーロー見出しには黄色の下線を入れる
- 角丸は控えめ。カードは `8px`
- 影は軽く、罫線中心で清潔に見せる
- 装飾グラデーション、紫、濃い青ベース、巨大なイラストは避ける

## ロゴ・アイコン

- 媒体マークは生成画像で作らない。利用可能な公開/公式系SVGをローカルに置いて `<img>` で表示する
- 現在の媒体ロゴ資産:
  - `public/brand/google-ads.svg`
  - `public/brand/meta.svg`
  - `public/brand/yahoo.svg`
- 媒体ロゴは商標なので、色・形を勝手に改変しない
- LP内の機能アイコン・人物イラストはSVGまたはCSSで表現する
- ぼやけるラスター画像をUIアイコンに使わない
- 機能アイコンはティール線画 + 薄いミント背景で統一する
- 課題セクションの人物イラストは細いグレー線 + ミント/ティールのアクセントにする
- ヒーロー右側のモックは実プロダクト画面の縮小ではなく、LP用に要点を圧縮した「AI相談体験」のUIとして作る
- ヒーローモックで最初に見せる要素は、媒体連携状態、KPIの変化、AI回答、やることリストの4つに絞る

## レイアウト

1. ヘッダー
   - 左に丸いロゴ風マークと「ちょこっとインハウス」
   - 中央に「できること」「安心設計」「利用イメージ」
   - 右にティールの「事前登録する」

2. ヒーロー
   - 左にコピー
   - 右に4:3固定のプロダクトモック
   - コピーは必ず以下:
     - `広告運用を`
     - `ちょこっと、インハウス化。`
   - 見出し下に黄色の下線
   - 右側モックは大きすぎない。余白を残す
   - モック内の文章は小さくしすぎず、1440px幅で「AIが相談に答える」ことが読める密度にする

3. 課題セクション
   - 白い大きなカード
   - 3つの悩みカード
   - 線画風人物イラストの雰囲気をCSSで表現

4. 解決セクション
   - 薄いミント背景
   - read-only連携 → AIが相談に応える → 人が判断し実行する、の3ステップ

5. 機能セクション
   - 4カード
   - 小さな線画風アイコン

6. 安心設計
   - AIは提案まで、人が意思決定者
   - read-only、自動変更なしを強調

7. 利用イメージ
   - チャット例とやることリスト
   - 「結論」「原因仮説」「人間向け作業手順」「自信度」を含める

8. 最終CTA
   - ティール背景
   - 黄色CTAと白CTA

## 禁止

- AI自動最適化、予算自動変更、キャンペーン自動停止を示す表現
- 青一色の一般的SaaS感
- ヒーロー右側のモックを大きくしすぎてコピーを圧迫すること
- カードの角丸を大きくしすぎること
- 画像モックにない派手な装飾
